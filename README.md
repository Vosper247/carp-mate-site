# carp-mate-site

The public website for Carp Mate, served by GitHub Pages at https://carpmateapp.com:
the homepage, the privacy policy (`/privacy/`) and support (`/support/`).

Plain static HTML and CSS: no build step, no analytics, no cookies, and nothing
loaded from another domain. Space Grotesk is self-hosted under the SIL Open
Font License (`fonts/OFL.txt`).

The privacy policy describes what the app's code does. When the app's data
handling changes, change the policy and its effective date first.
